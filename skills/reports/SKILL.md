# reports

Publish a report: a dated HTML artifact filed under a **report type** and
browsable on the platform's Reports page. Requires `AP_API_URL` and
`AP_API_TOKEN` in the environment (the platform injects them). All calls:
`-H "Authorization: Bearer $AP_API_TOKEN"`.

## The rules

- Your report must target a **declared type** (`reports/<name>/report.yaml`
  in the platform repo). Saving to an undeclared type is rejected; your API
  key can only write types whose `generator` is your agent.
- Send a **body fragment** — no `<html>`, `<head>`, or `<style>`. The
  platform wraps it in the report-kit shell.
- Use ONLY report-kit classes (`rk-*`). The platform sanitizes on ingest:
  unknown classes, styles, scripts, and event handlers are **stripped**, so
  anything off-contract silently disappears. If the element you need doesn't
  exist, say so in your run output instead of improvising markup.
- Same type+date(+time) saves **replace** — re-running a report is safe.

## Blessed markup

```html
<header class="rk-header">
  <h1 class="rk-title">Title</h1>
  <p class="rk-meta">dateline · counts · context</p>
</header>
<div class="rk-stat-row">
  <div class="rk-stat"><span class="rk-stat-value">23</span><span class="rk-stat-label">items</span></div>
</div>
<div class="rk-callout">Key takeaway.</div>              <!-- also: rk-callout-warning|danger|success -->
<section class="rk-section">
  <h2>Section <span class="rk-chip">9 items</span></h2>  <!-- rk-chip-accent to highlight -->
  <div class="rk-item">
    <span class="rk-item-title"><a href="https://…">Headline</a></span>
    <span class="rk-item-src">source.com</span>
    <p class="rk-item-sum">One-sentence summary.</p>
  </div>
</section>
<div class="rk-grid">…two-column content…</div>
<footer class="rk-footer">Generated by <agent> · run <id></footer>
```

Plain `h2/p/ul/table/blockquote/code` inside the fragment are styled by the
kit — use them freely. Links must be `https://`; images only as `data:` URIs.

## Charts (no JavaScript — server-rendered SVG)

Request themed SVG and embed it verbatim:

```bash
curl -s -X POST -H "Authorization: Bearer $AP_API_TOKEN" -H "Content-Type: application/json" \
  -d '{"kind":"bar","series":[{"values":[9,3,5]}],"labels":["ai","business","infra"],"title":"Items by topic"}' \
  "$AP_API_URL/api/report-kit/chart" | jq -r .svg
```

Kinds: `bar`, `line` (multi-series with `label` per series), `sparkline`
(single small series — set `"width":120,"height":32`), `donut` (one series +
`labels`). Embed the returned `<svg>` directly in your fragment.

## Save

```bash
jq -n --arg html "$(cat report.html)" \
  '{type:"daily-news", date:"2026-08-03", title:"Daily news", html:$html}' > /tmp/report.json
curl -s -X POST -H "Authorization: Bearer $AP_API_TOKEN" -H "Content-Type: application/json" \
  -d @/tmp/report.json "$AP_API_URL/api/reports"
```

`date` is `YYYY-MM-DD`. Intraday types also send `"time":"HH-MM"`; daily
types must not. A `meta` object (freeform JSON) rides along for anything
structured you want to keep with the report.
